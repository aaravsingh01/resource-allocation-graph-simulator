# Resource Allocation Graph Simulator

A graphical tool for simulating and analyzing resource allocation graphs to detect deadlocks.

## Features
- Interactive graph editor (add processes/resources)
- Visual representation of resource allocation
- Deadlock detection algorithm
- Step-by-step simulation

## Installation
1. Clone this repository
2. Ensure you have D3.js installed. You can include it in your HTML file or install it via npm.
3. Open `index.html` in a web browser
4. Start building your resource allocation graph

## Usage
- Click "Add Process" to add a process node (green)
- Click "Add Resource" to add a resource node (blue)
- Coming soon: Create edges between nodes
- Coming soon: Detect deadlocks
